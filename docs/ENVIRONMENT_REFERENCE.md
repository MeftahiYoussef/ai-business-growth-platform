## Frontend

- `NEXT_PUBLIC_API_URL`
- `NEXT_PUBLIC_AI_ASYNC_CONTENT_PLAN`
- `NEXT_PUBLIC_ASYNC_REPORTS_ENABLED`

Only `NEXT_PUBLIC_*` values are intentionally browser-visible. Never create `NEXT_PUBLIC_GROQ_API_KEY`, `NEXT_PUBLIC_DATABASE_URL`, or frontend Redis secrets.
